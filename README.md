# StudentAPI

A Spring Boot API for student records. Data is stored in a local PostgreSQL database named `student_db`, in the table `students`.

Every public path starts with `/api/v1`. Create and update requests use `StudentRequest` instead of the database entity. A missing student returns 404. Flyway SQL scripts own the schema. On startup Hibernate only validates that the entity matches the table. It does not change the schema.

## Stack

| Item | Choice |
|---|---|
| Java | 17 |
| Spring Boot | 4.1.0 |
| Web | `spring-boot-starter-webmvc` |
| Persistence | Spring Data JPA + PostgreSQL |
| Schema | Flyway (`V1` creates the table, `V2` adds a unique constraint on email) |
| Validation | Jakarta Validation |
| Build | Maven. This machine uses the installed Maven 3.9.9, not `mvnw.cmd` |

## Request flow

A browser or Postman calls `StudentController`. The controller turns a `StudentRequest` into a `Student`, or passes the path id to `StudentService`. The service reads and writes PostgreSQL through `StudentRepository`. When the id does not exist, the service throws `StudentNotFoundException`, and `GlobalExceptionHandler` writes that as HTTP 404.

## What each file does

### `StudentApiApplication.java`

The entry point. `main` calls `SpringApplication.run`. `@SpringBootApplication` scans components under `com.bahram.studentapi` and turns on auto-configuration. Without this class the application cannot start, and `@WebMvcTest` cannot find a configuration class.

### `StudentController.java`

The REST API. The class has three annotations:

- `@RestController`: method return values are written as JSON.
- `@RequestMapping("/api/v1")`: every path below gets this prefix.
- `@Validated`: makes `@Min(15)` on the path variable take effect.

The controller depends only on `StudentService`. It does not touch the database.

| Method | Path | Purpose |
|---|---|---|
| `addStudent` | `POST /api/v1/students` | Creates a student from the body. `@Valid` checks age, name, gender, and major first. Email is stored only when it has text. A blank email stays `null`. |
| `getStudents` | `GET /api/v1/students` | Returns every student. |
| `getStudent` | `GET /api/v1/students/{id}` | Returns one student by id. A missing id is 404. |
| `updateStudent` | `PUT /api/v1/students/{id}` | Updates the student identified by the path id. The body is also a `StudentRequest`, so a missing id in the body cannot insert a new row. |
| `deleteStudent` | `DELETE /api/v1/students/{id}` | Loads the student, then deletes that row. A missing id is 404. The response is the deleted record. |
| `getStudentByName` | `GET /api/v1/students/name/{name}` | Finds students by name. The result is a list. No match returns `[]`. |
| `studentsByMajor` | `GET /api/v1/students/major/{major}` | Finds students by major. The result is a list. |
| `studentByEmail` | `GET /api/v1/students/email/{email}` | Finds students by email. The result is a list. |
| `studentsOlderThan` | `GET /api/v1/students/older-than/{age}` | Finds students older than the given age. An age below 15 fails validation and returns 400. |

### `StudentRequest.java`

The shared request body for create and update. It is not a database table.

| Field | Rule | Why |
|---|---|---|
| `age` | `@NotNull` and `@Min(1)` | Age is required and must be at least 1. |
| `name` | `@NotBlank` | Rejects null, an empty string, and whitespace only. |
| `gender` | `@NotBlank` | Gender is required on create. |
| `major` | `@NotBlank` | Major is required on create. |
| `email` | no required annotation | Optional. A non-blank value is copied onto the student. |

The annotations sit on the DTO because `@Valid` on the controller checks the request body, not the `Student` entity.

### `Student.java`

The JPA entity for the `students` table. `@JsonPropertyOrder` fixes the JSON field order as `id`, `age`, `name`, `gender`, `email`, `major`.

| Field | Meaning |
|---|---|
| `id` | Primary key, generated by the database. |
| `age` | Age. The entity also has `@Min(1)`. The request is rejected by the DTO. |
| `name` | Name. `setName` changes only the name. It does not rewrite the email. |
| `gender` | Gender. |
| `email` | Email. `@Column(unique = true)` matches the database unique constraint. Several rows may have a null email, because a PostgreSQL unique constraint allows multiple `NULL` values. |
| `major` | Major. |

The four-argument constructor sets age, name, gender, and major. The controller calls `setEmail` when an email should be stored.

### `StudentRepository.java`

Extends `JpaRepository<Student, Integer>`, so `findAll`, `findById`, `save`, and `deleteById` are already available. Four query methods are declared by name:

- `findByName`: by name, returns a list.
- `findByMajor`: by major, returns a list.
- `findByEmail`: by email, returns a list.
- `findByAgeGreaterThan`: age greater than the given value, returns a list.

Name and email return lists so two matching rows do not throw `IncorrectResultSizeDataAccessException`.

### `StudentService.java`

The business layer. Query details live here, not in the controller.

- `getStudents`: loads every student.
- `getStudent`: loads one student by id. A missing id throws `StudentNotFoundException`.
- `addStudent`: saves a new student.
- `updateStudent`: loads the existing row by the path id, then copies age, name, gender, and major from the request. Email is replaced only when it is not blank. This does not insert a new row and does not update a different id.
- `deleteStudent`: loads the row, throws if it is missing, otherwise deletes it and returns the deleted object.
- `studentByName`, `studentsByMajor`, `studentByEmail`, `studentsOlderThan`: return the repository result as-is. The "age must be at least 15" rule is `@Min(15)` on the controller, not a check in this class.

### `StudentNotFoundException.java`

A runtime exception. The constructor takes the id. The message is `Student not found with id: ...`.

### `GlobalExceptionHandler.java`

`@RestControllerAdvice` handles `StudentNotFoundException`. The status is 404 and the body is the exception message. Get-by-id, update, and delete all use this handler.

### `application.properties`

Shared by every environment:

- Application name `StudentAPI`.
- Datasource `jdbc:postgresql://localhost:5432/student_db`, username `postgres`.
- Password comes from the environment variable `DB_PASSWORD`. It is not stored in the file.
- `spring.jpa.hibernate.ddl-auto=validate`: on startup, compare the entity with the table. A mismatch fails startup. The schema is not altered automatically.

### `application-dev.properties`

Loaded only when the `dev` profile is active. It turns on `show-sql` and formatted SQL so Hibernate statements are visible. Without that profile, SQL stays out of the logs.

### `V1__create_students.sql`

Creates the `students` table on the first startup: `id`, `age`, `name`, `email`, `gender`, `major`. `id` uses `generated by default as identity`.

### `V2__unique_student_email.sql`

Adds the unique constraint `uk_students_email` on `email`. A migration that Flyway has already applied must not be edited, or Flyway reports a checksum mismatch. Later schema changes belong in a new `V3__...sql` file.

### `pom.xml`

The Maven project file. Dependencies cover Web, DevTools, validation, JPA, the PostgreSQL driver, Flyway, and `spring-boot-starter-webmvc-test` for tests. The package plugin is `spring-boot-maven-plugin`.

## Tests

Neither test connects to PostgreSQL.

### `StudentServiceTest.java`

Uses Mockito to stand in for `StudentRepository`. `findById(1)` is stubbed to return empty, then the test asserts that `getStudent(1)` throws `StudentNotFoundException`. It only checks that the service throws when the student is missing.

### `StudentControllerTest.java`

`@WebMvcTest` starts only the web layer. `@MockitoBean` stands in for `StudentService` and makes `getStudent(1)` throw `StudentNotFoundException`. `MockMvc` calls `GET /api/v1/students/1` and expects status 404. It checks that the exception becomes a 404 after `GlobalExceptionHandler`.

## How to run

PostgreSQL 18 is installed at `D:\CYDEO\PostgreSQL\18`. The database name is `student_db`. Set the password in the same PowerShell window you use to start the app. The variable disappears when that window closes.

```powershell
$env:DB_PASSWORD = "your-database-password"
$env:SPRING_PROFILES_ACTIVE = "dev"
cd D:\github-repos\spring-boot\StudentAPI
mvn spring-boot:run
```

After `Started StudentApiApplication`, the server is at `http://localhost:8080`. With `dev` active, the log includes SQL.

Compile only, or run tests only:

```powershell
mvn compile
mvn test
```

`mvn test` does not need the database.
